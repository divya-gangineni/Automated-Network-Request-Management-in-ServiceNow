# Automated-Network-Request-Management-in-ServiceNow

## 📌 Project Overview

**Automated Network Request Management in ServiceNow** is a ServiceNow-based project designed to automate and streamline the process of submitting, processing, approving, tracking, and managing network-related requests.

The solution uses ServiceNow Service Catalog, variables, workflows/flows, approvals, notifications, and automation capabilities to reduce manual effort and improve the overall efficiency of network request management.

## 🎯 Project Objectives

* Automate the network request submission process.
* Provide a simple and structured request form for users.
* Capture all required network request information through catalog variables.
* Automate request routing and approval processes.
* Keep users informed through automated notifications.
* Improve request tracking and visibility.
* Reduce manual processing and administrative effort.
* Provide a centralized platform for managing network requests.

## ⚙️ Key Features

### 1. Service Catalog

A dedicated catalog item is created for submitting network-related requests.

### 2. Request Form

The catalog item contains appropriate variables to collect the required information from the requester.

### 3. Automated Request Processing

Submitted requests are processed automatically using ServiceNow automation and flow capabilities.

### 4. Approval Management

Requests requiring authorization are routed through the appropriate approval process.

### 5. Notifications

Automated notifications keep users and relevant teams informed about request submission, approval, progress, and completion.

### 6. Request Tracking

Users and administrators can track the status and progress of network requests within ServiceNow.

### 7. Centralized Management

All requests and related information are maintained within the ServiceNow platform for better visibility and management.
